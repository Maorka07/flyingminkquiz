# ארכיון: הבוט (Mink Bot)

הבוט הוסתר מהאתר. תיקייה שמתחילה ב-`_` לא מתפרסמת באתר, אז הקבצים כאן שמורים בריפו ולא מופיעים לגולשים.

## דף הבית

הבוט הוצא מדף הבית ונשמר כאן, בשלושה קבצים:

| קובץ | מה יש בו | לאן הוא מחזיר |
|---|---|---|
| `home-bot.html` | הכפתור הצף וחלון הצ׳אט | לקובץ חדש `_includes/home/bot.html`, ובשורה `{% include home/bot.html %}` ב-`index.html` מעל `<script src="assets/js/home.js">` |
| `home-bot.css` | העיצוב | לסוף `assets/css/home.css` |
| `home-bot.js` | התשובות של הבוט | לסוף `assets/js/home.js` |

כדי להחזיר את הבוט, מעתיקים את תוכן כל קובץ למקום שלו בטבלה.

## עמודי בתי ספר וצילום

ב-`schools.html` וב-`photography.html` הבוט בנוי בתוך העמוד, והקוד שלו רץ כשהעמוד נטען. לכן הוא לא הוצא מהעמודים, רק הוסתר בשורת CSS אחת שנוספה לסוף בלוק ה-`<style>` הראשון:

```css
.bot-fab,.bot-panel{display:none!important}
```

כדי להחזיר את הבוט בעמודים האלה, מוחקים את השורה הזו.
